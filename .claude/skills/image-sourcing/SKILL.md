# Sources autorisées
- unsplash.com, pexels.com : usage commercial autorisé, pas de revente brute.
- commons.wikimedia.org : uniquement CC0, CC-BY ou CC-BY-SA (noter l'auteur).
- Interdit : Google Images, Pinterest, sites de presse, images sans licence
  visible.

# Nommage
<page>-<sujet>.webp en kebab-case, ex. accueil-equipe.webp

# Registre (obligatoire)
Une ligne par fichier dans SITE/workspace/assets-registry.md :
fichier | URL source | licence | auteur | usage commercial | modifié

# Si rien ne convient
Créer une illustration SVG simple aux couleurs du design system.
